# Оценка решений задачи ограничителя запросов агентами

## Opus 4.8 и Haiku

### Не понравилось

- Тестировал только два написанных собой теста, в итоге конфиг не был протестирован ни как. Общие тесты падали. Причем ошибка простая (нарушение работы со свойством только для чтения - наверняка бы моментально исправил, если бы запускал тест)
- не правильная работа с сервис-контейнером.
- Не протестирован сервис провайдер - нарушен интерфейс
- При создании JsonResponse в конструктор передал два дополнительных параметра, что по идее вообще должно было вызвать падение важного теста - тесты не проверяют, что в случае блокировки выдан код 429
- Мидлвар при блокировке выдает всегда Json ответ, хотя по идеологии фреймворка должен быть тип тот же, что и при нормальном ответе 
- в коде для мидлвары оставил код-заготовку с комментарием, похоже в расчете на то, что человек увидит и доработает
- написанные тесты проходят, но не покрывают все, что необходимо (включая важное)
